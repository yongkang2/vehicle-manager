# Vehicle Data Management

Local Windows vehicle engineering workspace for vehicle records, controller and battery configurations, DOVE reports, attachments, history and shared-folder collaboration. Maintained product and security rules: README.md and the bundled user guide; API enforcement remains authoritative.

This redesign serves frequent desktop data-management tasks. English and Chinese remain supported. Preserve existing workflows, permissions, offline/sync recovery, confirmations, pagination and exports. No sample data is shipped into the application database.

Approved direction (2026-11-03): restrained, refined Stellantis-inspired color and layout, with a lightweight, responsive feel. No new production dependencies, remote fonts, decorative imagery or continuous animation.
